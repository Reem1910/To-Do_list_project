To-Do List Manager

To-Do List Manager is a simple task management application using Python. This application allows you to add tasks, view them, update their status, and delete them easily via a command-line interface (CLI).

Features ✨

Add tasks 📌

View task list 📋

Update task status (completed/incomplete) ✅❌

Delete tasks 🗑️

Easy-to-use command-line interface 💻

How to Run 🚀

1️⃣ Prerequisites

Make sure you have Python 3.x installed on your system.

2️⃣ Running the Application

Download or clone the repository to your device:

git clone https://github.com/your-username/todo-list-manager.git
cd todo-list-manager

Run the script:

python todo.py

Usage 🛠️

After running the application, you will see a menu with the following options:

 TO DO LIST MANAGER
1. Add Task
2. View Tasks
3. Update Task
4. Delete Task
5. Exit

1️⃣ Add a New Task

Select option 1, then enter the task name.

2️⃣ View All Tasks

Select option 2 to display the task list with their status (✓ completed, ✗ incomplete).

3️⃣ Update Task Status

Select option 3, then enter the number of the task you want to update.

4️⃣ Delete a Task

Select option 4, then enter the number of the task you want to delete.

5️⃣ Exit the Application

Select option 5 to terminate the program.
